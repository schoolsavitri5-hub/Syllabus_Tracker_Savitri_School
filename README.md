# Syllabus Tracker — Savitri Balika Inter College

School Syllabus Management & Academic Progress Tracking Portal for **Savitri Balika Inter College, Mirzapur (U.P.)**.

## 🚀 Features
- **Class-wise & Subject-wise Completion Bar Graphs**: Live interactive completion analytics with drill-down and color-coded status.
- **Academic Hierarchy Management**: 1st to 8th (Primary/Junior) & 9th to 12th (Senior) segregated syllabus tracking.
- **Excel Management**: Validate and bulk import syllabus sheets directly into the database.
- **Exam Pattern Filter**: Track progress based on UT 1, UT 2, Half Yearly, PA 1, PA 2, and Annual exams.
- **Practicals & Assessments Tracking**: Separate trackers for laboratory experiments and academic evaluations.
- **Responsive & Modern UI**: Fast, responsive interface with sidebar navigation, search, and official school branding.

## 🛠️ Tech Stack
- **Frontend**: React 18, Vite, React Router v7, Lucide Icons, Recharts
- **Backend & Database**: Supabase (PostgreSQL, Auth, RLS Policies)
- **Deployment**: Vercel / Netlify
